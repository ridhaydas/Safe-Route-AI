# 🛡️ SafeRoute AI

### AI-Powered Personal Safety and Emergency Assistance Platform

SafeRoute AI is an AI-powered personal safety platform designed to help users during emergency situations. It provides quick access to emergency assistance, location tracking, nearby safety services and AI-powered safety guidance.

The main goal of SafeRoute AI is to make personal safety easier, smarter and more accessible through technology.

## 🚀 Features

- **SOS Emergency Alert:** Quickly activate an emergency alert with a siren, vibration and location sharing.
- **Voice SOS:** Trigger emergency assistance using voice commands.
- **Live Location:** Get your current location and share it through Google Maps.
- **Nearby Safety Services:** Find nearby police stations and hospitals using interactive maps.
- **AI Safety Assistant:** Get AI-powered answers and safety guidance.
- **AI Safe Route Advisor:** Receive suggestions and guidance for safer travel routes.
- **Interactive Maps:** View locations using Leaflet maps.

## ⚙️ Installation and Setup

1. Clone this repository:

   `git clone https://github.com/ridhaydas/Safe-Route-AI.git`

2. Open the project folder.

3. Install the required dependencies:

   `npm install`

4. Create a `.env` file in the root directory and add your API key using the environment variable name required by the backend code.

5. Start the backend server using the start command configured in `package.json`.

6. Open the frontend in your browser as configured for the project.

## 🔐 Security

- API keys and sensitive credentials are stored in environment variables.
- The `.env` file is excluded from the GitHub repository.
